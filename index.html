Personal application · Google Drive

octopustransportau.website

A private, single-user application that connects its owner's own Google Drive account to a Linux workstation using rclone. It is not a public service: there is no sign-up, no multi-user front end, and no account other than the owner's.

What this application does

octopustransportau.website exists for one purpose: to let the owner work with the files in their own Google Drive as if they were ordinary folders on their own computer. Concretely, it lets the owner:

  • Mount their Google Drive as a local folder on their own Linux machine.
  • Browse folders and list files stored in that Drive account.
  • Download files from Drive and upload new or modified files back to Drive.
  • Keep a local cache so recently used files stay available when the network is slow.

Nothing is shared with other users, and no third party receives the owner's files.

How it works

  1. The owner authorizes the application once, through Google's standard OAuth 2.0 consent screen (installed/desktop application flow). Nothing is authorized until the owner explicitly approves that screen.
  2. The resulting refresh token is stored locally on the owner's machine, in ~/.config/rclone/rclone.conf (readable only by the owner).
  3. rclone uses that token to call the Google Drive API directly and exposes the Drive contents as a FUSE mount point on the same machine.

There is no intermediary server or backend database. API requests travel directly from the owner's workstation to Google. This website is static documentation only — it has no analytics, no cookies, and no forms.

Google API access

The application requests a single OAuth scope. It does not request access to Gmail, Calendar, Contacts, Photos, or any other Google product.

ScopeWhy it is required
https://www.googleapis.com/auth/drive Read, create, modify and delete files in the owner's own Google Drive. Full read/write access is required because the application mirrors a local folder tree to Drive: it must be able to list directories, download file contents, and upload changed files.

The scope is limited to the Drive account that the owner authorizes. The application does not offer any way to access another person's Drive data.
