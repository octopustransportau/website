Privacy Policy

octopustransportau.website is a private, single-user application operated by its owner. This page explains exactly what it accesses, where that data goes, and how to revoke access.

Effective date: 27 October 2026 · Last updated: 27 October 2026

1. Who operates this application

octopustransportau.website ("the application") is a personal project, operated by a single individual for their own use. It is not a commercial service and is not offered to the general public. There is exactly one user: the owner. Contact details are at the bottom of this page.

2. What data the application accesses

After the owner authorizes the application through Google's OAuth 2.0 consent screen, the application accesses the following, and only the following:

  • Google Drive files and metadata in the owner's own Drive account — file names, folder structure, sizes, timestamps, and file contents. This is required to list folders, download files, and upload changed files.
  • Basic account information returned by Google during authorization, such as the account's email address, used only to display which account is connected.

The application does not access Gmail, Google Calendar, Contacts, Google Photos, location data, or any other Google product, and it does not read data from any Google account other than the one the owner authorizes.

3. Where the data is stored

  • OAuth token — stored locally on the owner's own computer in ~/.config/rclone/rclone.conf, readable only by the owner's user account.
  • File cache — files downloaded or uploaded through the application may be cached temporarily in a local directory on the same computer, and removed by the application's cache policy.
  • No server-side storage — the application has no backend, no database, and no cloud storage of its own. No copy of the owner's files is kept anywhere other than the owner's computer and the owner's Google Drive.

4. How the data is used

The data is used solely to provide the file-management functionality described on the overview page: listing folders, downloading files, uploading files, and keeping a local cache so recently used files remain available.

Data is never used for advertising, profiling, analytics, or training machine-learning models.

5. Sharing and disclosure

Data received from Google APIs is not sold, rented, transferred, or disclosed to any third party. It is not used for any purpose other than those described above. The only external service the application communicates with is Google's own API endpoint.

This website is a set of static HTML files served by GitHub Pages. It sets no cookies, runs no analytics, and includes no third-party scripts, fonts, or trackers.

6. Google API Services User Data Policy — Limited Use

octopustransportau.website's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. In particular:

  • Data is used only to provide or improve the user-facing features described above.
  • Data is not transferred to third parties except as necessary to provide those features, to comply with applicable law, or as part of a merger or acquisition with prior user consent.
  • Data is not used for serving advertisements.
  • Data is not used to determine creditworthiness or for lending purposes.
  • Humans do not read the data, except where the owner gives explicit consent, where it is necessary for security purposes, to comply with applicable law, or for internal operations of the application itself.

7. Retention and deletion

Access tokens remain on the owner's machine until the owner revokes access or deletes the configuration file. Cached file copies can be deleted at any time by clearing the local cache directory. Because the application stores nothing on a server, there is no remote copy to request deletion of.

8. Revoking access

The owner — or any Google account holder who has authorized this application — can revoke access at any time at myaccount.google.com/permissions. Revocation immediately invalidates the stored token, and the application can no longer access Drive until it is authorized again.

9. Security

Tokens are stored in a file readable only by the owner's user account. Communication with Google uses HTTPS. The application runs locally and exposes no network service to the internet. No method of storage or transmission is perfectly secure, but the attack surface here is limited to a single machine owned by the operator.

10. Children

The application is not directed at children and is not offered to the public.

11. Changes to this policy

If this policy changes, the updated version will be published on this page with a new effective date. Material changes will be reflected here before the application is used under the new terms.
